### What the site may and may not repeat

The files are internal Step Up Education documents. The owner chose "method only": the site
describes how the work was done and never republishes pricing, subscription fees, competitor
teardowns, negative product feedback, or any parent's name or phone number. The sheet screenshots in
`src/assets/images/pika/` are curated extracts built from the real rows with those columns left out —
each caption names the file and sheet it came from.

## Numbers rule

Only figures that appear in a source file or screenshot reach the site, with their original framing.
The channel performance image is captioned as a one-month performance overview of the 01-31/05 report
and never as growth. The note beside it states that the figures are taken from that report unmodified;
it does not interpret the **-36,4% so với 32 ngày trước** reading the screenshot also carries.
